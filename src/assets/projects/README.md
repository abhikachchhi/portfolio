# Project media

Create one directory per project slug and keep that project's source media together:

```text
src/assets/projects/project-slug/hero.webp
src/assets/projects/project-slug/screen-01.webp
src/assets/projects/project-slug/demo.mp4
```

Import assets from the corresponding record in `src/data/projects.ts`. Add meaningful alternative text and image dimensions to the media object when real assets are introduced.
