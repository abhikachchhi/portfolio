# Practa webfont files

The supplied `Practa.otf` and `Practa-Outline.otf` files live here and are loaded through `src/styles/fonts.css`.

The accompanying `readme.txt` from Mauvais Jour states that the typeface is free to use with credit. Preserve that file with the fonts. A WOFF2 conversion can be added later for additional transfer-size optimization.
